# 면접 연습 앱

내 질문과 답변 스크립트로 **듣고 따라 말하는 연습**(연습모드)과, **카메라 앞에서 실제처럼 답하고 녹화·채점받는 연습**(실전모드)을 하는 앱입니다.

## 받기
- **git을 모르면**: 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
- **git을 쓰면**: `git clone https://github.com/inwoo-jang/interview-practice-kit.git`

## 준비물
- **Chrome** (음성 인식은 Chrome에서만 됩니다)
- **Python 3** (맥은 기본 설치되어 있음)

## 실행
- **맥**: `연습시작.command` 더블클릭 → Chrome이 열립니다
  - 처음에 "확인되지 않은 개발자" 경고가 뜨면 우클릭 → 열기
- **윈도우 / 직접 실행**: 이 폴더에서 `python3 server.py` (윈도우는 `python server.py`) → Chrome으로 http://localhost:8765 접속

## 내 질문 넣기
처음 열면 `질문_예시.md`의 공통 질문 21개가 들어 있습니다.

1. **연습모드** 위쪽의 **[템플릿 받기]** → `질문_템플릿.md` 다운로드
2. 템플릿 형식대로 내 질문과 답변을 채우기
   ```
   # 지원동기
   ## 왜 우리 회사에 지원했나요?
   - 시간: 60
   ### 답변
   ……때문에 지원했습니다. ……
   ```
3. **[md 가져오기]** → 파일 선택 → `확인` = 전부 바꾸기 / `취소` = 뒤에 이어 붙이기

앱 안에서도 바로 고칠 수 있습니다.
- **[+ 질문 추가]**, 질문 카드의 **[✎ 수정]**: 질문·카테고리·시간·답변·방향·팁 수정, **[삭제]**
- **[md 내보내기]**: 지금 질문 전체를 md로 저장 (백업·공유용)
- **[면접 이름·날짜]**: 홈 화면에 `OO회사 1차 면접 D-3`처럼 표시

내 질문은 `questions.json`에 저장되고, **git에는 올라가지 않습니다** (`.gitignore`).

## 연습모드 🎧
- 질문 → (생각할 시간) → 답변 스크립트를 소리로 들려줍니다
- **쉐도잉**: 질문을 듣고 내가 먼저 말한 뒤 스크립트와 비교
- 음성 파일이 없으면 **브라우저 음성(한국어)** 이 질문과 답변을 읽어 줍니다

## 실전모드 🎥
- 카메라를 켜고 **[시선 보정]** 한 번 → **[연습 시작]**
- 답변이 끝나면 **두괄식 점수**(결론까지 걸린 시간, 배경부터 시작했는지, 준비한 결론과 일치하는지, 문제·행동·결과·숫자, 길이), 말 속도, 필러("것 같습니다" 등), 시선, 미소를 리포트로 보여 줍니다
- **다운로드 폴더에 자동 저장** (설정 탭에서 끌 수 있음)
  - `Q03_q03_20261020-2230.webm` — 질문명·경과 시간·게이지·자막이 들어간 녹화 영상
  - `Q03_q03_20261020-2230_리포트.pdf` — 분석 리포트
  - `Q03` = 질문 번호 (질문 목록 순서)
- 처음 저장할 때 Chrome이 "여러 파일 다운로드"를 물으면 **허용**

## (선택) 자연스러운 음성 만들기
기본은 브라우저 음성입니다. **ElevenLabs API 키**가 있으면 더 자연스러운 음성 파일을 만들 수 있습니다.

1. 받은 **`elevenlabs.env`** 파일을 이 폴더(README.md가 있는 곳)에 넣기 — 또는 연습모드 위쪽 **[🔊 음성 설정]** → 키 붙여 넣기 → **[키 저장]**
2. **[모든 질문 음성 만들기]** 또는 질문 카드 [✎ 수정] → **[저장 + 음성 생성]**

- 키 파일(`elevenlabs.env`, `elevenlabs_key.local`)은 **git에 올라가지 않습니다.** 키를 코드나 채팅방 공개 글에 올리지 마세요.
- 만든 음성은 `audio/` 폴더에 저장되고, 이것도 git에는 올라가지 않습니다.
- 취침용·쉐도잉 묶음 파일은 `ffmpeg`가 있을 때만 만들어집니다 (`brew install ffmpeg`). 없으면 문항 음성만 만듭니다.
- 회사명·프로젝트명처럼 음성이 잘못 읽는 말은 `read_as.local.json`에 `[["LG CNS", "엘지 씨엔에스"]]` 형식으로 적어 두면 바꿔 읽습니다.
